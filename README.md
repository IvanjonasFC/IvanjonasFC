Soy Iván Jonás, desarrollador con perfil **DevOps**. Combino desarrollo full-stack (Java, Python, TypeScript) con administración de sistemas e infraestructura como código (Docker, Linux, CI/CD). ## Proyecto destacado: LifeOS — Suite familiar con IA

Suite SaaS familiar **autohospedada** con IA propia (**"Lito"**) que devuelve la soberanía de tus datos: vive en tu propio servidor, sin suscripciones ni terceros.

<p align="center"><img src="icon.png" alt="LifeOS" width="160" /></p>

- **Backend:** NestJS + PostgreSQL + TypeORM + BullMQ + Redis
- **Frontend:** Angular 18 + Ionic 8 (app Android)
- **IA propia "Lito":** RAG sobre pgvector/Qdrant + LLMs vía **Model Context Protocol (MCP)**
- **Infra:** multitenant con cifrado AES-GCM, seguridad JWT, i18n ES/EN, despliegue **Docker + Caddy**
- **Módulos:** chat cifrado, calendario, gastos con splits en tiempo real (WebSockets), lista de la compra, nube personal, notas y geolocalización, más un **panel de administración** (observabilidad de BD, migraciones y depurador de contenedores Docker)

## Home Lab e infraestructura (24/7)

~30 servicios en **Docker** sobre un **NAS Synology DS224+**, replicando arquitecturas de producción:

- **Red y acceso** — Caddy (TLS automático), WireGuard VPN, Cloudflare DNS + DDNS, AdGuard Home
- **Datos** — PostgreSQL, Redis, Qdrant + pgvector, MongoDB
- **Observabilidad** — Prometheus, Grafana, Loki, Tempo, cAdvisor
- **Entrega (GitOps)** — Forgejo (Git + CI/CD), n8n, Portainer
- **Media e IA local** — Jellyfin, LLMs locales; backups automatizados con pruebas de restauración
